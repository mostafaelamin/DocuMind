
# DocuMind — AI-Powered Document Assistant

**A local AI-powered PDF assistant designed to make document analysis and information retrieval more accessible.**

DocuMind is a Python application that allows users to upload PDF documents, ask questions about their contents, and receive AI-generated answers with page references through an interactive chat interface.

Powered by **Llama 3.2 through Ollama**, DocuMind runs AI inference locally without requiring paid APIs or sending document contents to an external AI provider.

## Features

- **PDF Text Extraction:** Extract and process text-based PDF documents using PyMuPDF.
- **AI-Powered Document Q&A:** Ask questions about uploaded documents and receive context-aware responses generated by Llama 3.2.
- **Conversational Chat:** Maintain recent conversation history within the active Streamlit session for follow-up questions.
- **Page References:** Generate page references in responses and inspect the original document text through a page-by-page source viewer.
- **Document Analytics:** Display document information, including page count, word count, and file size.
- **Interactive Dashboard:** Navigate a custom dark-themed Streamlit interface designed for document analysis.
- **Local AI Inference:** Run the language model through Ollama without requiring an external AI API key.

## Architecture

DocuMind uses a local document-processing and AI inference workflow:

```text
             User
              |
              v
      Streamlit Interface
              |
              v
         PDF Upload
              |
              v
    PyMuPDF Text Extraction
              |
              v
     Document Text + Chat
              |
              v
       Ollama / Llama 3.2
              |
              v
    AI-Generated Response
      with Page References
              |
              v
      Streamlit Dashboard
```

Streamlit manages the user interface and conversational session. PyMuPDF extracts text from uploaded PDFs, while Ollama runs Llama 3.2 locally to generate answers using the extracted document context.

## Getting Started

Follow these instructions to download and run DocuMind on your computer.

### Prerequisites

Before starting, ensure you have:

- **Python 3.12 or later**
- **Git** for cloning the repository
- **Ollama** installed from [ollama.com](https://ollama.com/)
- Sufficient RAM and storage to download and run Llama 3.2 locally
- An internet connection for the initial installation and model download

After the dependencies and model are installed, document processing and AI inference can run locally without an external AI API.

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/mostafaelamin/DocuMind.git
cd DocuMind
```

This downloads the project and navigates into its directory.

### 2. Create a Virtual Environment

A virtual environment keeps DocuMind's Python dependencies separate from other projects.

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows (PowerShell):**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Once activated, you should see `(.venv)` in your terminal.

### 3. Install Python Dependencies

With the virtual environment activated, run:

```bash
python -m pip install -r requirements.txt
```

This installs the Python packages required to run DocuMind.

### 4. Install and Configure Ollama

Download and install Ollama:

https://ollama.com/

After installation, open a terminal and download Llama 3.2:

```bash
ollama pull llama3.2
```

The model will be downloaded to your computer. This may take several minutes depending on your internet connection.

Verify the model is installed:

```bash
ollama list
```

You should see `llama3.2` among the available models.

**Important:** Ollama must be running while using DocuMind.

On macOS or Windows, launch the Ollama application if it is not already running.

Alternatively, if the Ollama server is not running, start it in a separate terminal:

```bash
ollama serve
```

Keep the Ollama server running while using DocuMind. Do not start a second server if Ollama is already running.

### 5. Launch DocuMind

Return to the project directory with your Python virtual environment activated.

Start the Streamlit application:

```bash
python -m streamlit run app.py
```

Streamlit should automatically open the application in your default browser.

If it does not open automatically, visit:

http://localhost:8501

### 6. Start Using DocuMind

Once the dashboard is open:

1. Upload a text-based PDF document using the file uploader.
2. Allow PyMuPDF to extract the document's text.
3. Enter a question about the document in the chat interface.
4. Review the AI-generated answer and any included page references.
5. Use the source text viewer to verify information against the original document.
6. Continue asking follow-up questions within the same session.

**Note:** DocuMind runs locally. The application and AI model must be running on your computer to use the dashboard.

## How It Works

DocuMind processes documents through the following workflow:

**1. Document Upload**

Users upload a PDF document through the Streamlit interface.

**2. Text Extraction**

PyMuPDF extracts text from the document and organizes it by page.

**3. Context Preparation**

DocuMind prepares up to the first 10,000 characters of extracted document text, along with recent conversation messages, for the language model.

**4. Local AI Inference**

The prepared context and user question are sent to Llama 3.2 through Ollama running on the local computer.

**5. Response Generation**

Llama 3.2 generates an answer based on the provided document context and is prompted to include relevant page references.

**6. Source Verification**

Users can inspect the extracted page text to verify AI-generated answers and citations.

## Limitations

DocuMind is an experimental document assistant and currently has the following limitations:

- **Document Size:** Only the first 10,000 characters of extracted text are included in the model context. Information beyond this limit may not be available for answering questions.
- **Citation Accuracy:** Page references are generated by the language model and are not automatically verified. Users should confirm important information using the source viewer.
- **Scanned PDFs:** Image-only or scanned PDFs without extractable text are not supported. OCR functionality has not yet been implemented.
- **Session-Based History:** Conversation history is maintained within the active Streamlit session and is not permanently stored.
- **Local Hardware Requirements:** Performance depends on the computer's available memory and processing capabilities.
- **Local Deployment:** DocuMind currently runs on the user's computer and does not have a publicly hosted interactive version.
